## Run

```sh
python3 main.py
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), refusing images over the gate limits (1 MiB, 1024x1024) and verifying the copy with a sha256 self-check. `draw.py` is the Pillow script that drew `entry.png` at build time.
